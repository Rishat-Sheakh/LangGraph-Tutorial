# LangGraph Tutorial

A collection of beginner-to-intermediate LangGraph workflows built while learning LangGraph and LangChain.

## Notebooks

- Environment Setup
- 1_BMI Workflow | Basic LangGraph workflow for BMI calculation |
- 2_Simple LLM Workflow | Simple LLM-based workflow using Google Gemini |

- 3_Prompt Chaining Blog Generator | Demonstrates prompt chaining with LangGraph |
- 4_Cricket Batsman Analyzer | Analyzes batsman statistics using a LangGraph workflow |

- 5_Essay Evaluation Workflow | Evaluates an essay using multiple evaluation criteria |

- 6_Quadratic Equation | Non-LLM workflow for solving quadratic equations using conditional routing |

- 7_Review_Reply_workflow | A LLM-based workflow that performs sentiment analysis on customer reviews and generates personalized responses based on the detected sentiment.
