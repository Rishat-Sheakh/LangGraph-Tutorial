# LangGraph Tutorial

A collection of beginner-to-intermediate LangGraph workflows built while learning LangGraph and LangChain.

## Projects

- Environment Setup
- BMI Workflow | Basic LangGraph workflow for BMI calculation |
- Simple LLM Workflow | Simple LLM-based workflow using Google Gemini |

- Prompt Chaining Blog Generator | Demonstrates prompt chaining with LangGraph |
- Cricket Batsman Analyzer | Analyzes batsman statistics using a LangGraph workflow |

- Essay Evaluation Workflow | Evaluates an essay using multiple evaluation criteria |

- Quadratic Equation | Non-LLM workflow for solving quadratic equations using conditional routing |

## Tech Stack

- Python
- LangGraph
- LangChain
- Google Gemini API
- Jupyter Notebook
